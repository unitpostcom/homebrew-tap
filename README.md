# Unitpost Homebrew tap

```bash
brew install unitpostcom/tap/unitpost
```

This installs the official [Unitpost CLI](https://www.unitpost.com/docs/cli), a standalone binary for macOS (Apple silicon and Intel) and Linux (x64 and arm64). It doesn't need Node.js. Upgrade with `brew upgrade unitpost`.

`Formula/unitpost.rb` is written by Unitpost's release pipeline on every CLI release, with checksums from the matching [release](https://github.com/unitpostcom/unitpost-cli/releases). Edits made here by hand are overwritten by the next release.

Problems with the CLI? Open an issue in [unitpostcom/unitpost-cli](https://github.com/unitpostcom/unitpost-cli/issues), or see the [docs](https://www.unitpost.com/docs/cli).
